# Ledger Match logo

`logo-source.png` is the user's original 500 × 500 RGBA image, preserved byte-for-byte.
SHA256: `160763a7a2b3e91fa10680c5c260462c002a68d1dddc3bbbbbfde9bb9b6ed8e2`.

The header uses `logo.png` (120 × 120). `favicon-32.png` is the PNG browser icon;
`../favicon.ico` contains 16, 32, 48 and 64 pixel versions of the same artwork.
Pillow's Lanczos resizing preserves the entire square canvas, transparency,
proportions and colors: no crop, recoloring, background or generated artwork.
Only the three display assets are copied into the public build; the original
and this note remain in the source repository.
